## Unity의 2D

Unity에서 2D 게임도 내부적으로는 3D 공간에 그립니다. 카메라를 **Orthographic**(원근 없음)으로 두고 X/Y 평면만 쓰는 방식입니다. 그래서 3D 기능(조명, 셰이더, 파티클)을 2D에 그대로 섞을 수 있습니다.

새 프로젝트는 **Universal 2D** 템플릿으로 만들면 2D 렌더러, 2D 조명, 관련 패키지가 미리 설정됩니다.

| 패키지 | 기능 |
|--------|------|
| 2D Sprite | 스프라이트 편집기 (슬라이스, 피벗) |
| 2D Tilemap Editor | 타일 기반 레벨 제작 |
| 2D Animation | 스프라이트 스켈레탈 애니메이션 |
| 2D Pixel Perfect | 픽셀 아트용 카메라 |
| 2D SpriteShape | 곡선 지형 |

## 스프라이트

### 임포트 설정

| 설정 | 설명 |
|------|------|
| **Sprite Mode** | Single(이미지 하나) / Multiple(스프라이트 시트 — Sprite Editor에서 슬라이스) |
| **Pixels Per Unit (PPU)** | 몇 픽셀이 월드의 1유닛인지. 프로젝트 전체에서 **통일**해야 크기가 맞음 |
| **Filter Mode** | 픽셀 아트는 **Point (no filter)**, 일반 일러스트는 Bilinear |
| **Compression** | 픽셀 아트는 None 또는 고품질 — 압축 아티팩트가 눈에 띔 |
| **Pivot** | 회전/위치 기준점. 캐릭터는 보통 발 밑(Bottom) |

### SpriteRenderer

```csharp
[SerializeField] private SpriteRenderer sr;

void FaceDirection(float x)
{
    if (x != 0f) sr.flipX = x < 0f;  // 좌우 반전
}

void SetHitFlash(bool on)
{
    sr.color = on ? Color.red : Color.white;
}
```

### 그리기 순서 (Sorting)

2D는 깊이 대신 **정렬 순서**로 앞뒤를 정합니다.

1. **Sorting Layer**: Background → Ground → Characters → Effects → Foreground 처럼 큰 단위
2. **Order in Layer**: 같은 레이어 안의 순서 (숫자가 클수록 앞)
3. 그래도 같으면 카메라 거리 / 커스텀 축

탑다운 RPG처럼 **Y 좌표가 낮을수록(화면 아래일수록) 앞에** 그려야 한다면, URP 2D Renderer의 **Transparency Sort Mode = Custom Axis, (0, 1, 0)**으로 설정합니다. 여러 스프라이트로 이뤄진 캐릭터는 루트에 **Sorting Group**을 붙여 한 덩어리로 정렬합니다.

## Tilemap

격자 기반 레벨을 그림 그리듯 칠해서 만듭니다.

```
Grid
├── Tilemap_Ground   (TilemapRenderer + TilemapCollider2D + CompositeCollider2D)
├── Tilemap_Walls
└── Tilemap_Decor    (충돌 없음, 장식)
```

1. Hierarchy → **2D Object → Tilemap → Rectangular**
2. **Window → 2D → Tile Palette**에서 팔레트 생성 → 스프라이트를 드래그하면 Tile 에셋 생성
3. 브러시로 칠하기

### 충돌 최적화

`TilemapCollider2D`만 쓰면 타일마다 콜라이더가 생겨 수천 개가 됩니다. **CompositeCollider2D**를 함께 붙이고 TilemapCollider2D의 **Composite Operation**(구버전: Used By Composite)을 설정하면 인접 타일 콜라이더가 하나의 외곽선으로 합쳐집니다. 이때 Rigidbody2D는 **Static**으로 둡니다.

### Rule Tile

주변 타일에 따라 모양이 자동으로 바뀌는 타일입니다(모서리, 벽 끝 처리). **2D Tilemap Extras** 패키지에 포함되어 있습니다.

### 코드로 타일 다루기

```csharp
using UnityEngine;
using UnityEngine.Tilemaps;

public class TileDigger : MonoBehaviour
{
    [SerializeField] private Tilemap ground;

    public void Dig(Vector3 worldPos)
    {
        Vector3Int cell = ground.WorldToCell(worldPos);
        if (ground.HasTile(cell))
            ground.SetTile(cell, null);
    }
}
```

## 2D 물리

```csharp
[RequireComponent(typeof(Rigidbody2D))]
public class PlatformerController : MonoBehaviour
{
    [SerializeField] private float moveSpeed = 7f;
    [SerializeField] private float jumpForce = 14f;
    [SerializeField] private Transform groundCheck;
    [SerializeField] private LayerMask groundMask;

    private Rigidbody2D rb;
    private float inputX;
    private bool jumpQueued;

    void Awake() => rb = GetComponent<Rigidbody2D>();

    public void SetInput(float x, bool jumpPressed)
    {
        inputX = x;
        if (jumpPressed) jumpQueued = true;
    }

    void FixedUpdate()
    {
        bool grounded = Physics2D.OverlapCircle(groundCheck.position, 0.1f, groundMask);

        rb.linearVelocity = new Vector2(inputX * moveSpeed, rb.linearVelocity.y);

        if (jumpQueued && grounded)
            rb.linearVelocity = new Vector2(rb.linearVelocity.x, jumpForce);
        jumpQueued = false;
    }
}
```

### Body Type

| 타입 | 설명 |
|------|------|
| **Dynamic** | 중력·힘 적용 (플레이어, 상자) |
| **Kinematic** | 코드로 이동, 다른 물체를 밀지만 자신은 밀리지 않음 (움직이는 발판) |
| **Static** | 움직이지 않음 (벽, 바닥) |

- 캐릭터가 넘어지지 않게 **Constraints → Freeze Rotation Z**
- 벽에 붙어서 떨어지지 않는 문제는 콜라이더에 **마찰 0의 Physics Material 2D**를 붙여 해결

### 플랫포머 조작감 팁

물리 그대로만 쓰면 점프가 둥둥 뜨는 느낌이 납니다. 장르 게임들이 공통으로 쓰는 보정 기법입니다.

| 기법 | 내용 |
|------|------|
| **코요테 타임** | 발판에서 떨어진 직후 0.1초 정도는 점프 허용 |
| **점프 버퍼** | 착지 직전 0.1초 안에 누른 점프도 착지 순간 실행 |
| **가변 점프 높이** | 버튼을 일찍 떼면 상승 속도를 줄임 |
| **낙하 가속** | 하강 시 중력 배율을 높여 묵직한 느낌 |

```csharp
// 낙하 시 중력 강화 + 버튼 떼면 짧은 점프
if (rb.linearVelocity.y < 0f)
    rb.gravityScale = 3f;
else if (rb.linearVelocity.y > 0f && !jumpHeld)
    rb.gravityScale = 2f;
else
    rb.gravityScale = 1f;
```

## 2D 조명

URP 2D Renderer는 2D 전용 조명(**Light 2D**)을 제공합니다.

- **Global Light 2D**: 전체 밝기 — 밤 장면은 낮게
- **Spot Light 2D**: 원형/부채꼴 조명 (횃불, 손전등)
- **Freeform / Sprite Light 2D**: 모양을 직접 지정
- **Shadow Caster 2D**: 그림자를 만드는 오브젝트
- 스프라이트에 **Normal Map**을 추가하면 2D에서도 입체감 있는 조명 반응

## 픽셀 아트 카메라

픽셀 아트 게임은 화면 해상도에 따라 픽셀 크기가 들쭉날쭉해지거나 움직일 때 떨리는 문제가 있습니다. 카메라에 **Pixel Perfect Camera** 컴포넌트를 붙이고 Assets PPU와 기준 해상도(예: 320×180)를 지정하면 정수 배율로 맞춰 렌더링합니다.

```
Cinemachine Camera
├── Follow: Player
└── Cinemachine Confiner 2D
      └── Bounding Shape: PolygonCollider2D (맵 경계)
```

카메라가 맵 밖을 비추지 않게 하는 가장 간단한 방법입니다.

## 정리

- 2D는 Orthographic 카메라 + X/Y 평면이며, 앞뒤는 Sorting Layer / Order in Layer로 정합니다.
- 스프라이트 PPU는 프로젝트 전체에서 통일하고, 픽셀 아트는 Point 필터 + Pixel Perfect Camera를 씁니다.
- Tilemap 충돌은 CompositeCollider2D로 합칩니다.
- 2D 물리는 `Rigidbody2D`/`Physics2D`를 쓰고, 코요테 타임·점프 버퍼 등으로 조작감을 다듬습니다.
